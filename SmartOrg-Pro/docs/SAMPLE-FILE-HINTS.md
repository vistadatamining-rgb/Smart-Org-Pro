# Sample file – hints and tips (text for the "How to use" page of SmartOrg-Pro-sample.pbix)

Put this text in a text box on the first report page, next to a working Smart Org Pro visual that
uses `sample/SmartOrg-Pro-sample-data.csv`.

**Getting started**
1. Drop *Employee ID* and *Manager ID* into the matching wells (both required). Top of the chart = rows with an empty Manager ID.
2. Add Name, Title, Department, Photo URL and Performance % to enrich the cards.
3. Add measures to *Data card values* (+ optional *targets* / *previous period*) for the KPI area.

**Interaction**
- Click a card → filters the other visuals on the page. Ctrl+click → several people. Click empty space → clear.
- Right-click a card → standard Power BI menu (Show data, Include/Exclude, Drill through…).
- Click `+` / `−` → collapse or expand a branch. Ctrl + mouse wheel → zoom.

**Format pane**: Card style, Layout, Theme, Connector, Progress bar, Legend, KPI Performance, Zoom, License, About (includes the privacy policy link).
